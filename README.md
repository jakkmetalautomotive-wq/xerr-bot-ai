# xerr-bot-ai — บอท LINE OA ของ XERR AUTOTEAM

บอทตอบลูกค้าใน LINE ด้วย AI (Gemini) โดยอ่านคำตอบจาก Google Sheet · ตอบไม่ได้ → ส่งต่อแอดมิน

## บรีฟ

**ร้าน / ตอบในนาม:** แอดมินผู้ชายของร้าน XERR AUTOTEAM (กรอบป้ายทะเบียนรถ ขายตรงจากโรงงาน ส่งจากกรุงเทพ)
**โทน:** สุภาพ เป็นกันเอง ลงท้าย "ครับ / ครับผม" · emoji นิดหน่อย · 1–3 ประโยค
**ไม่มีใน FAQ:** "ขอบคุณที่สอบถามครับ 🙏 เรื่องนี้ขอให้แอดมินตรวจสอบให้ก่อนนะครับ" + บอกเวลาแอดมินตอบ (จ.–ส. 09:00–18:00) + แจ้งแอดมินทาง LINE

### 1. โครงไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `app/api/line-webhook/route.ts` | รับข้อความจาก LINE · ตรวจลายเซ็น · ตอบ "ได้รับแล้ว" ทันที แล้วทำงานต่อเบื้องหลัง |
| `lib/bot.ts` | ลำดับการตอบ 1 ข้อความ (myid / รูป / ข้อความ) · ส่งต่อแอดมิน |
| `lib/sheet.ts` | ดึง FAQ จาก Google Sheet (CSV) · จำไว้ 60 วิ · ดึงไม่ได้ใช้ชุดเก่า |
| `lib/gemini.ts` | เรียก Gemini (temperature 1.0 · maxOutputTokens 1024 · log finishReason / thoughtsTokenCount / candidatesTokenCount · MAX_TOKENS → ข้อความมาตรฐาน) |
| `lib/prompt.ts` | System Prompt: `<role>` → `<constraints>` → `<output_format>` → `<faq>` แล้วคำถามลูกค้าใน `<question>` ท้ายสุด |
| `lib/shop.ts` | ข้อความมาตรฐานของร้าน + เวลาทำการแอดมิน (แก้ข้อความที่นี่) |
| `lib/history.ts` | จำ 4 รอบล่าสุดของลูกค้าแต่ละคน (แบบจำได้ถ้าโชคดี — Vercel อาจล้าง) |

### 2. Google Sheet (FAQ)
ใส่ **ลิงก์ Google Sheet ธรรมดา** (ลิงก์แชร์ / `/edit`) ใน `SHEET_CSV_URL` ได้เลย — บอทอ่าน 4 แท็บตามชื่อเอง: สินค้าและราคา · ค่าส่ง โปร ชำระเงิน · Q&A · คลิป YouTube (เปลี่ยนรายการแท็บได้ด้วย `SHEET_TABS` คั่นด้วย comma) · ไฟล์ต้องแชร์ "ทุกคนที่มีลิงก์ → ผู้มีสิทธิ์อ่าน" · จะใส่ลิงก์ CSV ทีละแท็บ (คั่นด้วย comma) ก็ได้เหมือนเดิม
- **Q&A** — `หมวด | คำถามลูกค้า (ตัวอย่าง) | คำตอบแนะนำ (โทนร้าน) | บอทตอบเอง / ส่งต่อ | ที่มา`
- **สินค้าและราคา** — `รหัส | สินค้า | ราคาปกติ | ราคาสั่งตรง LINE | ส่วนลด | ขนาด | วัสดุ/แบบ | สี/ลาย | ในชุดมี | คลิปวิธีติดตั้ง | หมายเหตุ`
- (แนะนำ) **ค่าส่ง โปร ชำระเงิน** — ใส่เป็นลิงก์ที่ 3 ได้
- แถวแรกต้องเป็นหัวคอลัมน์ · เพิ่ม/แก้แถวได้เลย บอทเห็นภายใน 1 นาที · **ห้ามใส่เลขบัญชีหรือข้อมูลลับ** (ลิงก์ CSV เป็นสาธารณะ)

**วิธีเอาลิงก์ CSV:** เปิด Sheet → ไฟล์ → แชร์ → เผยแพร่ทางเว็บ → เลือกแท็บ → เลือก "ค่าที่คั่นด้วยจุลภาค (.csv)" → เผยแพร่ → คัดลอกลิงก์ (ทำทีละแท็บ)

### 2.1 การ์ดรูปให้ลูกค้าเลือก (แท็บ "รูปสินค้า")
เพิ่มแท็บชื่อ **รูปสินค้า** หัวคอลัมน์: `ชุดรูป | ลำดับ | ชื่อแบบ | ราคา | ลิงก์รูป | รายละเอียด | ลิงก์คลิป` (ลิงก์คลิปไม่บังคับ)
- แถวที่ `ชุดรูป` เหมือนกัน = การ์ดชุดเดียวกัน (ปัดดูได้ สูงสุด 12 ใบ) · `ลำดับ` = เลขบนปุ่ม "เลือกแบบที่ N"
- `ลิงก์รูป`: ลิงก์แชร์ Google Drive (ไฟล์ต้องแชร์ "ทุกคนที่มีลิงก์" · JPG/PNG ไม่เกิน 10 MB) หรือลิงก์รูป https ตรง ๆ
- AI เลือกเองว่าคำถามไหนควรส่งการ์ดชุดไหน · ลูกค้ากดปุ่ม → บอทได้ข้อความ "เลือกแบบที่ N: ชื่อแบบ (ชุดรูป)"
- **เลือกเป็นขั้นตอน:** ตั้งชื่อชุดว่า `<สินค้า> ขั้น 1 ...`, `<สินค้า> ขั้น 2 ...` → บอทส่งการ์ดทีละขั้น ลูกค้ากดเลือกแล้วส่งขั้นถัดไปเอง · ปุ่มพกตัวเลือกก่อนหน้า ("| เลือกแล้ว: ...") บอทจึงสรุปได้ครบ
- **ข้ามขั้น:** ใส่ `ข้ามขั้นXXX` ในช่องรายละเอียดของแบบนั้น → ข้ามชุดที่ชื่อมี XXX
- **ขั้น 0 เลือกประเภทสินค้า:** ชุดชื่อ `เลือกประเภทสินค้า` · `ชื่อแบบ` = ชื่อสินค้าที่ใช้ตั้งชื่อชุดขั้นตอน (เช่น `สแตนเลส` ↔ `สแตนเลส ขั้น 1 เลือกทรง`) · ราคาบนการ์ดนี้ถ้ามีราคาเดียว (เช่น ABS `199.-`) ใช้คิดยอดได้เลย · สินค้าที่ไม่มีชุดขั้นตอน (ไร้ขอบ) กดแล้วเข้าขั้นสั่งซื้อทันที
- **ปุ่มด่วนแทนการ์ด:** ชุดที่ไม่ใส่ `ลิงก์รูป` เลยสักแถว = ตัวเลือกง่าย → ส่งเป็นปุ่มใต้ข้อความ (ป้ายปุ่มไม่เกิน 20 ตัวอักษร รวมราคา — ตั้งชื่อแบบให้สั้น)
- **กรอบป้ายภาษีอย่างเดียว** (ชื่อสินค้ามีคำว่า "ป้ายภาษี") → สรุปยอดเลย ค่าส่ง 15.- ไม่ชวนซื้อเพิ่ม
- ยังไม่มีแท็บนี้ → ใช้ชุดตัวอย่างในโค้ด (`lib/images.ts` › `sampleSets`) รูปประกอบชั่วคราวใน `public/samples` (สร้างจากโค้ด มีคำว่า "ภาพประกอบ"):

| ประเภท | ขั้นตอน (การ์ด = ต้องเห็นภาพ · ปุ่ม = ตัวเลือกง่าย) | ราคา |
|---|---|---|
| อะคริลิค | สี มี/ไร้เส้นขอบ 7 แบบ (การ์ด) → ขนาด (การ์ด) → เส้นคาดกลาง (การ์ด) | 399 / 419 |
| สแตนเลส | ทรง (การ์ด) → แผ่นใส (ปุ่ม) | 279 / 319 |
| เหล็กพ่นสี | สี ขาว/ดำ (ปุ่ม) → ทรง (การ์ด) → แผ่นใส (ปุ่ม) | 249 / 299 |
| พลาสติก ABS | สี (ปุ่ม) → เส้นคาดกลาง (ปุ่ม) | 199 |
| ไร้ขอบ | ไม่มีตัวเลือก | 199 |
| รถตู้/บรรทุก | วัสดุ สแตนเลส / เหล็กพ่นสีขาว / ดำ (ปุ่ม) | 399 |
| กรอบป้ายภาษี พรบ. | รถยนต์ / มอเตอร์ไซค์ (ปุ่ม) · ค่าส่ง 15 | 69 / 129 |

- **การ์ดวิธีติดตั้ง:** ชุดชื่อ `วิธีติดตั้ง` · แถวที่ใส่ `ลิงก์คลิป` (YouTube) → ปุ่ม "▶ ดูคลิปวิธีติดตั้ง" เปิดคลิปเลย · ไม่ใส่ `ลิงก์รูป` = ใช้ภาพปกคลิปอัตโนมัติ · แถวไม่มีคลิป = ไม่มีปุ่ม (เขียนขั้นตอนในรายละเอียด) · ถ้าแท็บนี้ยังไม่มีชุด `วิธีติดตั้ง` บอทใช้การ์ด 8 รุ่นในโค้ด (อะคริลิค · สแตนเลส · เหล็กพ่นสี · ABS · ไร้ขอบ · รถตู้/บรรทุก · ป้ายภาษีรถยนต์ · ป้ายภาษีมอเตอร์ไซค์) โดย **ลิงก์คลิปอ่านจากคอลัมน์ `คลิปวิธีติดตั้ง` ในแท็บสินค้าและราคา** ตามรหัส (`acrylic-ss` · `stainless` · `steel` · `abs` · `borderless` · `truck` · `tax-car` · `tax-moto`) — แก้ลิงก์ในชีท บอทเปลี่ยนตามใน 1 นาที
- **การ์ดรีวิวสินค้า:** ชุดชื่อ `รีวิวสินค้า` ปุ่ม "⭐ ดูรีวิว" เปิดหน้ารีวิว (Canva) · แสดงเฉพาะรุ่นที่มีลิงก์ · ลิงก์ตั้งต้นในโค้ด (`lib/images.ts` › `PRODUCT_ROWS`): อะคริลิค · สแตนเลส · เหล็กพ่นสี · ABS · รถตู้/บรรทุก · **เพิ่ม/เปลี่ยนเองได้** โดยเพิ่มคอลัมน์ `ลิงก์รีวิว` ในแท็บสินค้าและราคา แล้วใส่ลิงก์ในแถวของรหัสนั้น (ใส่ในแถวไร้ขอบ / ป้ายภาษี → การ์ดรุ่นนั้นขึ้นเอง) · รูปบนการ์ด = รูปประเภทสินค้า (Canva ไม่มีภาพตัวอย่างให้ดึง)

### 2.2 Rich Menu (เมนูใต้แชท)
2 แถว × 3 ช่อง (เลย์เอาต์ใน `lib/richmenu.ts`):

| | ซ้าย | กลาง | ขวา |
|---|---|---|---|
| แถวบน | 🛒 สั่งซื้อ (การ์ดประเภทสินค้า) | 💰 ราคา (รายการราคา + ค่าส่ง) | 🔧 วิธีติดตั้ง (การ์ดแต่ละรุ่น เปิดคลิป YouTube) |
| แถวล่าง | ⭐ รีวิวสินค้า (การ์ดรีวิว เปิดหน้า Canva) | 💬 คุยกับแอดมิน (แจ้งแอดมินทันที) | ว่าง (กดแล้วไม่มีอะไร) |

ปุ่มส่งข้อความตาม `MENU` ใน `lib/shop.ts` · จะใช้ช่องที่ 6 → แก้ `null` ใน `RICH_MENU_LAYOUT` เป็นข้อความปุ่ม
- ติดตั้ง: เปิด `https://xerr-bot-ai.vercel.app/api/richmenu?key=<HEALTH_KEY>&apply=1` (ไม่ใส่ `&apply=1` = ดูว่าตอนนี้ตั้งเมนูไหนไว้)
- กดซ้ำได้ — สร้างเมนูใหม่แล้วลบเมนูชื่อ "XERR เมนูหลัก" อันเก่า (เมนูอื่นไม่แตะ)
- รูปเมนู `public/richmenu.png` (**2500 × 1686** พิกเซล · PNG/JPG ไม่เกิน 1 MB · ช่องกว้าง 833 / 834 / 833 สูงแถวละ 843 ตามตารางด้านบน) — ทำรูปใหม่ก็วางทับไฟล์นี้ชื่อเดิม แล้ว deploy + กดลิงก์ติดตั้งซ้ำ · เมนูที่ตั้งผ่าน API ขึ้นแทนเมนูที่ตั้งใน LINE OA Manager

### 3. System Prompt
ดู `lib/prompt.ts` — ตอบจาก `<faq>` เท่านั้น · ห้ามแต่งราคา/เวลา/ที่ตั้ง · ห้ามรวมยอดเงินเอง (ส่งต่อแอดมินสรุปยอด) · ไม่มีคำตอบ → ข้อความมาตรฐาน · คำตอบเป็น JSON `{reply, needs_admin, admin_note}` เพื่อให้ระบบรู้ว่าต้องแจ้งแอดมินไหม (ลูกค้าเห็นแค่ `reply` ภาษาไทยไม่มี markdown)

### 4. ลำดับการทำงาน
1. LINE ส่งข้อความมา → ตรวจลายเซ็น (ปลอม = 401)
2. ตอบ LINE `200` ทันที แล้วทำงานต่อเบื้องหลัง (`waitUntil`)
3. แสดง "กำลังพิมพ์..." → ดึง FAQ (cache 60 วิ) → ถาม Gemini (timeout 8 วิ) → reply
4. ต้องการแอดมิน → ต่อท้ายข้อความบอกเวลาแอดมิน + push แจ้ง `ADMIN_LINE_USER_ID`
- พิมพ์ `myid` → บอทตอบ LINE user ID (เอาไปใส่ `ADMIN_LINE_USER_ID`)
- ลูกค้าส่งรูป/ไฟล์ (สลิป รูปของเสียหาย) → ไม่ผ่าน AI ส่งต่อแอดมินทันที

### 5. เมื่อมีปัญหา
| ปัญหา | บอททำอะไร |
|---|---|
| ดึง Sheet ไม่ได้ | ใช้ FAQ ชุดล่าสุดที่จำไว้ · ถ้าไม่มีเลย → ขอโทษลูกค้า + แจ้งแอดมิน |
| Gemini ช้า/ล่ม (เกิน 8 วิ) | ขอโทษลูกค้า + แจ้งแอดมิน |
| Gemini ตอบยาวจนถูกตัด (MAX_TOKENS) / อ่านคำตอบไม่ได้ | ส่งข้อความมาตรฐาน + แจ้งแอดมิน (ไม่ส่งครึ่งประโยค) |
| LINE reply ไม่ได้ (token หมดอายุ) | ส่งแบบ push แทน (กินโควตาข้อความ) |
ดู log ได้ที่ Vercel › Project › Logs (ค้นคำว่า `[gemini]`, `[bot]`, `[line]`)

## สั่งซื้อ (สรุปยอด → แบบฟอร์มที่อยู่ → แอดมินกดยืนยันรับเงิน)
1. ลูกค้ากดการ์ดครบทุกขั้น → บอทชวนเพิ่มกรอบป้ายภาษี (ปุ่ม เพิ่ม / ไม่เพิ่ม)
2. บอทส่งสรุปออเดอร์ (เลขออเดอร์ XR-xxxx · **ยอดคิดด้วยโค้ด**: ราคาจากการ์ดที่มีราคาเดียว + ป้ายภาษี 69 + ค่าส่ง 30/ฟรี) + เลขบัญชี (`PAYMENT_INFO`) + ปุ่ม "กรอกชื่อ-ที่อยู่จัดส่ง"
3. ลูกค้ากรอกแบบฟอร์มในแอป LINE (`/order`, LIFF) → `/api/order` ตรวจตัวตนลูกค้า (ID token) + ลายเซ็นออเดอร์ → แจ้งแอดมินพร้อมปุ่ม ✅ ได้รับเงินแล้ว / ❌ ยอดไม่ตรง
4. ลูกค้าส่งสลิปในแชท → บอทแจ้งแอดมิน · แอดมินเช็คยอดแล้วกดปุ่ม → บอทแจ้งลูกค้า
- ไม่มีฐานข้อมูล: ข้อมูลออเดอร์ติดไปกับปุ่ม/ลิงก์ และเซ็นกำกับด้วย `LINE_CHANNEL_SECRET`
- ต้องตั้ง: `ADMIN_LINE_USER_ID`, `PAYMENT_INFO`, `LIFF_ID`, `LINE_LOGIN_CHANNEL_ID`
- ข้อความ push (แจ้งแอดมิน / แจ้งลูกค้าหลังยืนยันเงิน) นับโควตาข้อความของแพ็กเกจ LINE OA
